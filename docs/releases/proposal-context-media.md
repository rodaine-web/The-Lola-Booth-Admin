# Proposal imagery and content context — 2026-11-20

Proposal composition uses the requested business/celebration audience and the selected experience together. The reviewed pricing quote supplies business context, including when stale presentation fields still say Wedding. Custom business and activation event labels resolve to their appropriate professional copy.

Virtual Booth has dedicated digital-access copy and a laptop example from the approved corporate reference. Its images fit in the frame without cropping the device away. Activation examples reuse the approved reference photography; corporate proposals use professional event photographs for the selected experience. Unknown experiences receive no guessed Glam photograph. Unscoped global/experience media cannot automatically cross event audiences; explicit per-proposal approved selections remain available.

Legacy render fallbacks also select by context, and legacy automatic filename-prefix photo sets are excluded for business requests. Retail/catalog prices, commercial inclusions and agreed document snapshots are unchanged. Existing issued proposal snapshots are not regenerated by this release; new proposals and regenerated draft previews use the corrected rules.

Validation covers actual database proposal creation with a business Virtual quote and stale Wedding fields, matched images and copy, custom event normalization, activation examples, unknown experience fallback, override preservation, source regressions, and representative HTML/PDF generation.
