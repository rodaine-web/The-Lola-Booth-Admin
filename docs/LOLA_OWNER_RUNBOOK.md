# LOLA Owner Runbook

## Daily Workflow

1. Open Dashboard and Live Operations.
2. Review Needs Attention, overdue invoices, failed integrations, and unread critical notifications.
3. Open System Health if anything looks off.
4. Confirm upcoming events have staff, equipment, creative details, and payment status ready.

## New Lead

1. Open Sales > Leads.
2. Review source, event date, city, package/experience interest, and notes.
3. Contact the lead and log the communication.
4. Convert to client/event when qualified.

## Proposal

1. Create or open the proposal from Sales > Proposals.
2. Confirm client, event, package, add-ons, pricing, terms, and branded PDF preview.
3. Send the proposal.
4. Track public views and acceptance.

## Payment

1. Open the invoice.
2. Confirm balance and due date.
3. Use online provider status only when System Health shows configured/verified.
4. Record manual payments when needed.
5. Reconcile refunds from Finance > Payments.

## Event Prep

1. Assign staff and equipment.
2. Complete readiness checklist items.
3. Send staff brief.
4. Print or save run sheet.
5. Generate QR labels for equipment if needed.

## Event Day

1. Use Operations > Live.
2. Attendants use My Events for acknowledgements, checklist, status transitions, incident reporting, and equipment scan.
3. If internet is poor, continue with offline actions and sync after reconnect.

## Post-Event

1. Return/check equipment.
2. Resolve incidents.
3. Mark event complete.
4. Prepare gallery delivery.
5. Send gallery and review follow-up if configured.

## When Something Is Down

- Email down: use in-app records and send manually until provider recovers.
- Payment provider down: use offline payment instructions and reconcile later.
- Worker stale: open System Health, restart worker, retry safe failed jobs.
- QR unreadable: use manual asset UID entry.
- Gallery unavailable: verify delivery token, expiration, and gallery URL.
