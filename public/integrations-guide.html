Integration setup guide

Configure integrations through System → Integrations. A catalog listing does not authorize access or enable synchronization.

Connection states

Connected means the portal has provider evidence. Configured means settings exist but connectivity is unverified. Needs Setup and Approval Required need administrator action. Coming Soon has no working connector. Local payload tests never prove external delivery.

Supported connections

Microsoft 365 contact discovery requires approved shared-mailbox access. Results require review and import; discovery never sends campaigns. Google Analytics, Meta, TikTok and Mailchimp use their existing OAuth flows, account selection and logs. Some require provider approval.

Stripe settings are managed on the server and in payment settings. PayPal remains disabled pending qualification. Twilio requires configured credentials, opt-in and escalation rules. Website publishing uses the native CMS / Public API.

Developer and security guidance

Use the authenticated existing API, permission checks, encrypted integration registry and signed webhook endpoints. Never place provider credentials in browser code or local storage. Ask an authorized administrator for environment configuration; credentials must not be sent by email.

Marketing lead ingestion is separate from promotional consent. Accounting connectors are planned and must preserve the native invoice and payment workflow.
